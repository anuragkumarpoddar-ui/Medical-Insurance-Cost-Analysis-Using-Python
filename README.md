# Medical Insurance Cost Analysis Using Python

### Turning Insurance Data into Meaningful Insights

## Project Overview

This project uses **Exploratory Data Analysis (EDA)** to analyse medical insurance charges and identify patterns associated with age, BMI, smoking status, sex, number of children, and region.

The goal is to understand which factors show the strongest relationship with medical insurance costs using data analysis and visualisation techniques.

## Key Analysis

- Data cleaning and quality checks
- Descriptive statistics and feature distributions
- Univariate and bivariate analysis
- Correlation and multivariate analysis
- Hypothesis evaluation
- Business insights and recommendations

## Key Findings

- **Smoking Status:** Shows the strongest observed association with insurance charges.
- **Age:** Shows a positive relationship with insurance costs.
- **BMI:** Shows a weaker positive relationship with insurance charges.
- **Other Features:** Sex, number of children, and region are also explored to understand differences in charges.


## Project Outcome

This project demonstrates practical skills in Python, data cleaning, exploratory data analysis, statistical interpretation, and data visualisation. The findings can support further analysis and predictive modelling of medical insurance charges.
